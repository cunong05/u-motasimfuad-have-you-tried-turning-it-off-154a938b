# Have You Tried Turning It Off?

Entry for make.fun's **"Have You Tried Turning It Off?"** bounty ($10 in USDC).
Write one funny line, under 200 characters, spoken by a desperate tech support
agent to a desperate customer. An AI judge compares the lines pairwise in
3 blind rounds.

## Entry

> "Have you tried turning it off and on again? No? Then have you tried turning yourself off and on again — the problem might be you."

## How to run

```bash
python3 main.py
cat /output/entry.txt
```

`main.py` validates the entry (under 200 characters, exactly one line) and
writes it to `/output/entry.txt`.
